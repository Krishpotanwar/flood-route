# Data terms tracker

Draft v0.1, 2026-10-05. Living document: update a row whenever a reply, a licence text or a registration screen is seen. Nothing here has been requested, registered or signed. Not legal advice.

**Tags.** **[V url]** = I opened that official page or document in this session and it says this. **[U]** = everything else. A [U] may carry a pointer: *secondary* = a news, vendor or community page I opened; *snippet* = search-result text only, page not opened. URLs are written without `https://` to keep rows short.

**Commercial use and redistribution columns** use only yes / no / unknown, followed by the tag. "Free to read" never counts as yes.
